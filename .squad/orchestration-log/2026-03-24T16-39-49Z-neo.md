## Task

Evaluate Orleans 10 SQLite provider options for Phase 2 local-silo architecture.

## Outcome

**Recommended:** Official `Microsoft.Orleans.Persistence.AdoNet` (10.0.x) + `Microsoft.Data.Sqlite`

### Key Decision Points

- **Provider:** ADO.NET (first-party, test coverage, DDL scripts included)
- **Driver:** Microsoft.Data.Sqlite (now properly registered in Orleans 10)
- **Clustering:** UseLocalhostClustering() — no external membership DB needed
- **Schema:** Run Sqlite-Main.sql + Sqlite-Persistence.sql on first launch
- **File location:** `{appDataFolder}/SquadScout/squadscout.db`

### Rationale

1. Phase 2 is single-silo, single-user. SQLite's single-writer model is a non-issue.
2. No clustering or reminders DB scripts exist, but both are unnecessary for our constraints.
3. Zero infrastructure footprint — just a .db file.
4. Official support in Orleans main; tested in test suite.
5. Easy migration path to server DB later (just change invariant + connection string).

### Risks Identified

- GitHub issue dotnet/orleans#8187 (2022, still open) flagged older version issues.
- Source inspection confirms fixed on Orleans 10 main.
- **Mitigation:** Smoke test early in Phase 2 implementation.
